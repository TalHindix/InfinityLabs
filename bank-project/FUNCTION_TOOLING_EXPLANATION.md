# Function Tooling - הסבר ברמה גבוהה

## מה זה Function Tooling?

**Function Tooling** (או Function Calling) הוא מנגנון שמאפשר ל-LLM (Large Language Model) כמו GPT-4 לקרוא לפונקציות בקוד שלך במקום רק להחזיר טקסט.

## הרעיון המרכזי

במקום שהמודל רק "מדבר" עם המשתמש, הוא יכול גם **לבצע פעולות** - לקרוא למידע מהמסד נתונים, לבצע העברות כסף, לשלוח אימיילים, וכו'.

## דוגמה קונקרטית - Banking Chatbot

### תרחיש: משתמש שואל "תראה לי את היתרה וההיסטוריה"

**Round 1:**
- **משתמש:** "תראה לי את היתרה וההיסטוריה"
- **מודל:** "אני צריך 2 פונקציות: `get_balance` ו-`get_transaction_history`"
- **שרת:** מריץ את שתיהן במקביל
- **תוצאות:** `{balance: 5000}` ו-`{transactions: [...]}`

**Round 2:**
- **מודל:** מקבל את התוצאות ומחליט מה לענות
- **מודל:** "היתרה שלך היא 5,000 AED. הנה 5 העסקאות האחרונות: ..."
- **משתמש:** רואה תשובה מלאה

## יתרונות

1. **דינמיות** - המודל מחליט מתי לקרוא לפונקציות לפי ההקשר
2. **פעולות אמיתיות** - לא רק טקסט, אלא ביצוע פעולות במערכת
3. **גמישות** - המודל יכול לקרוא לכמה פונקציות במקביל או ברצף
4. **אבטחה** - השרת שולט איזה פונקציות זמינות ואיך הן מתבצעות

## אתגרים ופתרונות

### אתגר 1: לולאות אינסופיות
**בעיה:** המודל יכול לבקש function calls ללא סוף  
**פתרון:** הגבלה של 5 rounds (MAX_TOOL_CALL_ROUNDS)

### אתגר 2: ביצועים
**בעיה:** אם יש כמה function calls, רצים אותם ברצף (איטי)  
**פתרון:** הרצה במקביל עם `Promise.all()`

### אתגר 3: שגיאות
**בעיה:** מה קורה אם function call נכשל?  
**פתרון:** try-catch שמחזיר error message למודל, והמודל מחליט איך להמשיך

## השוואה: עם ובלי Function Tooling

### בלי Function Tooling:
```
משתמש: "תראה לי את היתרה"
מודל: "אני לא יכול לגשת למידע שלך, אבל אתה יכול לבדוק באפליקציה"
```

### עם Function Tooling:
```
משתמש: "תראה לי את היתרה"
מודל: [קורא ל-get_balance] → "היתרה שלך היא 5,000 AED"
```

## נקודות חשובות לראיון

1. **המודל מחליט** - אנחנו לא אומרים לו מה לעשות, רק נותנים לו כלים
2. **לולאה** - זה תהליך איטרטיבי: request → execute → response → repeat
3. **מקביליות** - מריצים כמה function calls במקביל לביצועים טובים יותר
4. **בטיחות** - הגבלות על מספר rounds, validation של parameters, error handling

## דיאגרמת זרימה מפורטת

```
User Message
    │
    ▼
Build Messages (with history + system prompt)
    │
    ▼
Call OpenAI API (with available tools)
    │
    ├─► Has tool_calls? ──YES──► Execute all tools in parallel
    │                              │
    │                              ▼
    │                          Add results to messages
    │                              │
    │                              ▼
    │                          Call OpenAI again
    │                              │
    │                              └──► Loop (max 5 rounds)
    │
    └─► NO tool_calls ──► Return final text response
                              │
                              ▼
                          Send to user
```

## סיכום

Function Tooling מאפשר ל-LLM להיות לא רק "דובר", אלא גם "עושה" - לבצע פעולות אמיתיות במערכת. זה הופך chatbots מ-"יועצים" ל-"עוזרים פעילים" שיכולים לעזור למשתמשים לבצע משימות אמיתיות.
